# Проверка IRON PULSE v5

Последний запуск: 6 ноября 2026, Unity 6000.0.37f1, Windows / HDRP.

**69 из 69 проверок пройдены. Ошибок, исключений и assertions во время прогона нет.**

Полный результат: [v5.json](v5.json). Предыдущий прогон: [v4.json](v4.json).

Проверены движение, направленные рывки и двойной прыжок; огонь и переключение трёх видов оружия; физическая подача патронов в дробовик; девять вариантов добивания, разворот и реакции жертвы, лечение и выход камеры; удар F, накопление и расход ульты, поражение группы врагов, защита стенами, блокировка оружия и возврат к кулаку. Проверены 52 записанных звуковых эффекта, отсутствие фоновой музыки, HDRP-материалы, тени и сглаживание.

Новые проверки: два рывка подряд в противоположных направлениях, запрет третьего с пустым запасом, последовательное восстановление, отсутствие автоповтора при удержании Shift, использование восстановленного заряда, два воздушных рывка без расхода прыжков, пауза и сброс запаса. Для новых добиваний проверены реальные отделённые части: две голени и закрытые срезы головы после подсечки; обе отделённые руки до смертельного разреза шеи при ближнем захвате. Каждое добивание регистрирует ровно одно убийство и одно восстановление здоровья.

Среднее время кадра в JSON относится к автоматизированному прогону с отключённым ИИ исходной волны. Это диагностическая метрика, а не обещание частоты кадров в произвольном бою.

`IPSmokeTest.Run(outputDirectory)` запускается явно в Play Mode. Проверка создаёт временные клавиатуру и мышь, управляет игроком, создаёт тестовых врагов и возвращает исходные настройки ввода после завершения. При обычной игре компонент не запускается.

Меню редактора **Iron Pulse → Run Gameplay Validation** запускает этот же прогон. Результат runner хранится в `iron-pulse-editor-validation-status.json` рядом с отчётом; завершённый прогон имеет `state: Passed` и `checkCount: 69`.
