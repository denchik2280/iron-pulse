# IRON PULSE

Арена-шутер от первого лица на Unity 6: быстрые рывки, двойной прыжок, три вида оружия, киборги и контекстные добивания. Визуальный стиль — угловатые 3D-модели с мелкими ретро-фактурами, HDRP-освещением и тенями.

## Запуск

1. Установите **Unity 6000.0.37f1** через Unity Hub.
2. Добавьте корневую папку этого репозитория как Unity-проект. При первом открытии Unity восстановит пакеты и создаст локальную папку `Library`.
3. Откройте сцену [IronPulse_Arena](Assets/IronPulse/Scenes/IronPulse_Arena.unity).
4. Нажмите **Play**, перейдите в окно **Game** и нажмите **Enter**.

Используются HDRP 17.0.3 и Input System 1.12.0; версии закреплены в `Packages/manifest.json` и `Packages/packages-lock.json`.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / мышь | Движение / обзор |
| Shift + направление | Рывок |
| Space, затем Space в воздухе | Двойной прыжок |
| ЛКМ | Стрельба |
| 1 / 2 / 3, колесо мыши | Пистолет / автомат / двустволка |
| R | Перезарядка двустволки |
| E | Добивание оглушённого врага с оранжевым контуром |
| F | Удар левой рукой; при полном заряде — ульта катаной |
| Esc | Пауза |
| M | Включить / выключить звук |
| F2 | Разрешение кадра: 720 / 1080 / 1440 по высоте |

У пистолета и автомата бесконечные патроны без перезарядки. У двустволки два выстрела и быстрая перезарядка; пустой дробовик перезаряжается автоматически.

Попадания и убийства наполняют шкалу ульты. Заряженная атака на F выполняет три рубящих прохода катаной по группе врагов. Обычный удар и ульта учитывают стены; во время атаки оружие временно опускается.

Добивание восстанавливает 35 здоровья. Его вариант зависит от движения при нажатии E: направление рывка, боковое движение, подъём, падение сверху или подход со спины. Игрок хватает и разворачивает жертву, использует голую руку вместе с катаной; киборги реагируют корпусом, головой и конечностями.

## Содержимое проекта

- `Assets/IronPulse/Scripts` — игрок, оружие, враги, бой, интерфейс и воспроизведение звука.
- `Assets/IronPulse/Scenes` — игровая арена.
- `Assets/IronPulse/Resources/Audio/IronPulse` — 52 записанных звуковых эффекта.
- `Assets/Settings` — настройки HDRP.
- `Packages` и `ProjectSettings` — зависимости и настройки, необходимые для восстановления проекта.

`Library`, `Temp`, логи, сборки и локальные настройки IDE не хранятся в Git.

## Звук и лицензии

Фоновой музыки нет. Для выстрелов, катаны, механизмов, ударов и шагов используются записи с лицензией **CC0**. Источники, авторы и описание обработки перечислены в [AudioSources.txt](Assets/IronPulse/Resources/Audio/IronPulse/AudioSources.txt); точные границы монтажа — в соседнем `SampleEdits.json`.

## Проверки

`IPSmokeTest` содержит интеграционные проверки движения, оружия, добиваний, рукопашного удара, ульты, преград, звуковой библиотеки и ошибок исполнения. Компонент запускается явно для проверки и не включается при обычной игре.

Последний прогон: **54/54**, без ошибок исполнения. Подробности и ограничения измерения приведены в [отчёте проверки](Docs/Validation/README.md).
